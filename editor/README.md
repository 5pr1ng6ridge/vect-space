# VECTSPACE Story Editor

独立的 Tauri 2 剧情图编辑器，用于编辑 VECTSPACE `game/manifest.yaml` 和
`game/scenes/*.yaml`。

## 启动

在仓库根目录运行：

```powershell
npm --prefix editor install
npm run editor:dev
```

也可以在 `editor/` 目录运行：

```powershell
npm run tauri dev
```

如果当前终端找不到 Cargo，请先把 Rust 工具链加入 `PATH`：

```powershell
$env:PATH = "$env:USERPROFILE\.cargo\bin;$env:PATH"
```

发布构建：

```powershell
npm run editor:build
```

NSIS 安装包位于：

```text
editor/src-tauri/target/release/bundle/nsis/
```

## 使用方式

1. 选择仓库根目录或包含 `manifest.yaml` 的 `game/` 目录。
2. 在左侧切换场景、素材、项目设置或问题列表。
3. 从节点右侧端口拖线到目标节点。连线会直接修改 YAML 的跳转字段。
4. 在右侧检查器编辑所选节点。所有当前运行时节点均有类型化表单，
   `condition` 与条件选项使用可递归的条件构建器。
5. 在“项目”页声明 `save` / `profile` 变量、类型和默认值。
6. 使用左侧“问题”标签修复错误，再保存项目；点击问题可直接定位场景和节点。
7. 双击时间线节点进入独占工作区。工作区会通过真实 Rust RuntimeEngine 从当前
   Scene 入口构造进入状态，只询问该 Scene 内目标节点之前的分支选项，并复用游戏的
   Pixi、视频、音频和特效预览；预览路径只保存在 `.vectspace/layout-v1.json`，
   不会写入剧情 YAML 或玩家进度。时间线工作区的画布直接实例化共享的
   `SceneSurface` + `TimelineSession`（每个画布一份，与游戏端同一份实现）：对象创建、
   纹理引用计数、差分帧相位、闪白/震动与视频生命周期只有一套代码；预览默认静音，
   首次取消静音时才创建 Web Audio 图，拖动播放头只做确定性定位且不发声。
8. 顶栏“章节地图”进入独占地图工作区；拖放 Scene 或图片素材创建热点和装饰，
   坐标吸附到 20px 网格，并以左上角为原点直接对应游戏 1920×1080 地图页面的
   世界坐标。地图不会从剧情 Jump 自动生成。

素材导入会先经过 Rust 检查，确认格式、尺寸/时长、大小和哈希后才进入不透明的
暂存会话。导入清单中的 ID、类型和目标文件名可在提交前修改；保存项目时素材与
manifest、Scene 和地图一起进入可恢复事务，未保存或撤销的导入不会写入正式
`game/assets`。素材面板会显示引用位置；仍被剧情、时间线、地图或运行时约定引用
的素材不能从 manifest 移除。

素材也可以登记为循环帧动画：在素材面板中选择静态图片并创建帧动画，面板会预览
帧顺序、时长、尺寸和总解码预算。动画素材可以用于背景、立绘、GUI、按钮、地图和
长文本纸张；同一动画的帧必须保持像素尺寸一致。项目页的角色表支持默认表情、锚点、
偏移和缩放；动作库支持可参数化的相对通道动作，双击动作卡片进入复用同一时间线编辑器的
关键帧工作区，引用动作节点可一键解除为关键帧时间线。章节热点的「揭示策略」与「重演策略」
相互独立：始终显示 + 始终可重演的章节在到达前即可进入，也不会被报为不可到达。

## 长文本节点

“长文本”用于替代对话框显示较长的数学讲解。检查器中的每一“步骤”对应一次玩家
推进：已完成步骤会保留在同一组草稿纸上，当前步骤继续逐字显示。勾选“在此步骤前
分页”会在该步骤前开始一张新纸；不勾选时，运行时会依据实际排版高度自动接到下一张。

- 每个步骤都必须有稳定且唯一的 ID 和非空文本。
- `paper` 可选；选择已登记的 GUI 素材可作为纸张底图，未选择时稿纸区域完全透明。
- 文本支持与 `say` 相同的 KaTeX、插值、暂停、速度和文本效果标记。
- 编辑器预览使用与游戏相同的 `@vectspace/text` 标记解析、KaTeX 配置和视觉行分页；
  自动分页可以在一个很长的步骤内部换页，但不会拆开一条公式。`manual` 模式只在
  作者添加的分页标记处换页，超出的单页会向下扩展。
- 全屏工作区顶部可播放/暂停当前步骤、补全文字、进入下一步骤或从头重播。播放控制
  使用游戏同一套纯文字揭示会话；预览纸张和正文层始终以同一滚动位置移动。
- 运行时与存档会保存已写出的步骤，不保存当前滚动位置或打字动画。

## 文件与安全行为

- YAML 使用游戏本身的 Rust 数据类型、严格解析器和跨引用校验器。
- 保存前先验证完整候选项目，不会将已知无效的内容写入磁盘。
- 保存检查打开项目时的 SHA-256 指纹，防止覆盖外部编辑。
- 只序列化并替换字节实际变化的文档。
- 多文件保存先写入 `.vectspace/tmp/<save-id>/`；旧文件按相对路径备份到
  `.vectspace/backups/<save-id>/`，最多保留最近 10 代。这两类恢复数据均被 Git 忽略。
- 节点位置和画布视口写入 `game/.vectspace/layout-v1.json`，不污染剧情 YAML。
- 删除场景或素材登记不会删除原素材/YAML 文件，以便恢复。
- 只有实际修改的 YAML 文档会被规范化输出；未修改文档保留原字节（包括注释和手工
  格式）。多文件保存失败时会从事务备份恢复；备份和临时文件位于被 Git 忽略的
  `.vectspace/backups/`、`.vectspace/tmp/`，并保留最近 10 代。

## 快捷键

- `Ctrl+S`：保存
- `Ctrl+Z`：撤销
- `Ctrl+Y` 或 `Ctrl+Shift+Z`：重做
- Windows WebView2 的浏览器级右键菜单、刷新/导航、新窗口、查看源代码、DevTools、缩放和 `F1`–`F12` 快捷键已关闭。
