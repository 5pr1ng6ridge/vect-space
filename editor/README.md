# VECTSPACE Story Editor

独立的 Tauri 2 剧情图编辑器，用于编辑 VECTSPACE `game/manifest.yaml` 和
`game/scenes/*.yaml`。

这个东西应该没有发布的打算，只是给开发者制作作品用的。（

## 启动

在仓库根目录运行：

```powershell
npm --prefix editor install
npm run editor:dev
```

也可以在 `editor/` 目录运行：

```powershell
npm run tauri dev
```

如果当前终端找不到 Cargo，请先把 Rust 工具链加入 `PATH`：

```powershell
$env:PATH = "$env:USERPROFILE\.cargo\bin;$env:PATH"
```

发布构建：

```powershell
npm run editor:build
```

NSIS 安装包位于：

```text
target/release/bundle/nsis/
```

## 使用方式

1. 选择仓库根目录或包含 `manifest.yaml` 的 `game/` 目录。
2. 最左侧的活动栏切换左侧面板：场景、素材、角色、变量、资源库（UI 动效 / 按钮模板 /
   立绘动作）、问题，底部是项目设置。顶栏有项目 / 场景切换、全项目搜索（`Ctrl+F`）、
   章节地图、游戏预览、撤销 / 重做与保存；底部状态栏显示所选节点与问题数。
3. 从节点右侧端口拖线到目标节点。连线会直接修改 YAML 的跳转字段。
4. 在右侧检查器编辑所选节点。所有当前运行时节点均有类型化表单，
   `condition` 与条件选项使用可递归的条件构建器。
5. 在“变量”面板声明 `save` / `profile` 变量、类型和默认值。
6. 使用“问题”面板（按场景分组）修复错误，再保存项目；点击问题可直接定位场景和节点。
7. 添加节点：画布左上角「添加节点 ▾」、右键画布「在此处添加节点」、节点两侧的 ＋，或
   右键节点「在前面 / 后面插入」。双击普通节点会聚焦检查器的第一个字段；要看效果，
   选中节点按 `Ctrl+Enter` 或右键「从此处预览」，会先提交未保存的编辑再从该节点开始实时
   游戏预览（空格 / `Enter` 推进）。顶栏「游戏预览」按钮用选定起点打开同一预览。预览舞台
   内会显示鼠标在 1920×1080 设计坐标下的读数，离开舞台即隐藏。
   布局组：`Ctrl/⌘`（或 `Shift`）点击可加选节点或组框，右键「将所选项组成父组」或
   `Ctrl+L` 将它们组合；只选中一个组时右键「解散此组」或按 `Ctrl+L` 解散该层，子节点 / 子组仍保留。
   若浏览器/WebView 占用 `Ctrl+L`，改按 `Ctrl+Shift+L` 或使用右键菜单。组框只在与
   边框或标题栏交互时可选，拖动标题栏会带着全部后代节点整块吸附移动；组数据保存在
   `.vectspace/layout-v1.json`，可嵌套。
8. 双击 `timeline` 节点进入其独占工作区。工作区会通过真实 Rust RuntimeEngine 从当前
   Scene 入口构造进入状态，只询问该 Scene 内目标节点之前的分支选项，并复用游戏的
   Pixi、视频、音频和特效预览；预览路径只保存在 `.vectspace/layout-v1.json`，
   不会写入剧情 YAML 或玩家进度。时间线工作区的画布直接实例化共享的
   `SceneSurface` + `TimelineSession`（每个画布一份，与游戏端同一份实现）：对象创建、
   纹理引用计数、差分帧相位、闪白/震动与视频生命周期只有一套代码；预览默认静音，
   首次取消静音时才创建 Web Audio 图，拖动播放头只做确定性定位且不发声。
9. 顶栏“章节地图”进入独占地图工作区；拖放 Scene 或图片素材创建热点和装饰，
   坐标吸附到 20px 网格，并以左上角为原点直接对应游戏 1920×1080 地图页面的
   世界坐标。滚轮缩放，`Delete` 删除选中对象，方向键按网格移动。地图不会从剧情
   Jump 自动生成。
10. 所有全屏工作区共用一个顶栏（`editor/src/shell/WorkspaceHeader.tsx`）：返回、对象、
    工具、撤销 / 重做 / 保存。`Esc` 依次关闭菜单、取消拖拽、让输入框失焦，最后才返回剧情图。

## 画面节点与实时预览

- 检查器只编辑 Rust 规范化后的规范形状：背景转场是
  `{ type: cut|cross_fade|fade_through_color|wipe|push, ... }`（wipe/push 带四向
  `direction` 与 `softness`，`fade_through_color` 带颜色），屏幕效果是
  `{ type: flash, color, peak_alpha }` 或
  `{ type: shake, amplitude_x, amplitude_y, frequency_hz, decay, seed }`。
  旧的一词 YAML 仍可加载，保存时会写回规范形状。
- 「背景」「幕布」「屏幕效果」检查器都内嵌一个共享 `SceneSurface` 预览：真实纹理缓存、
  共享求值器与共享动画时钟，静音、可取消，并在 React Strict Mode 下复用同一个 Pixi
  应用与帧源。播放/暂停/继续之外还有「转场前 / 转场后」与进度滑杆，定位是确定性的：
  同一组参数与同一虚拟时刻总是产生同一帧。
- 幕布节点支持 `cover`/`reveal`、颜色或 `gui` 素材填充、`fade`、四向 `wipe`、
  `split_horizontal`/`split_vertical`、时长、缓动与 `await`；预览画布是 1920×1080。
- 环境声节点使用固定 `slot_1`–`slot_4` 和独立 ambience bus；时间线可分别自动化四个
  槽位的音量，预览默认静音且点击「声音」后才激活。游戏和编辑器通过共享只读
  `AudioDiagnostics` 检查素材、音量、相位与暂停状态；`ambience_lab` 在章节地图中可达。
- 素材引用统计、重命名与删除保护覆盖幕布的 `gui` 填充；`transition_lab` 演示场景可在
  游戏中手工走查全部五种背景转场、幕布组合与参数化效果。

素材导入会先经过 Rust 检查，确认格式、尺寸/时长、大小和哈希后才进入不透明的
暂存会话。导入清单中的 ID、类型和目标文件名可在提交前修改；保存项目时素材与
manifest、Scene 和地图一起进入可恢复事务，未保存或撤销的导入不会写入正式
`game/assets`。素材面板会显示引用位置；仍被剧情、时间线、地图或运行时约定引用
的素材不能从 manifest 移除。

素材也可以登记为循环帧动画：在素材面板中选择静态图片并创建帧动画，面板会预览
帧顺序、时长、尺寸和总解码预算。动画素材可以用于背景、立绘、GUI、按钮、地图和
长文本纸张；同一动画的帧必须保持像素尺寸一致。“角色”面板支持默认表情、锚点、
偏移和缩放；“资源库”面板的动作库支持可参数化的相对通道动作，点行上的铅笔按钮进入复用
同一时间线编辑器的关键帧工作区，引用动作节点可在检查器「⋯」菜单中展开为关键帧时间线。章节热点的「揭示策略」与「重演策略」
相互独立：始终显示 + 始终可重演的章节在到达前即可进入，也不会被报为不可到达。

## 统一的关键帧界面

剧情时间线、立绘动作、按钮模板与 UI 动效共用同一个中立关键帧界面
（`editor/src/components/TimelineSurface.tsx`）：同一把时间尺与播放头、同一套走带控件、
拖框多选、关键帧拖动、缓动（含 cubic-bezier）检查器、`Delete` 与 `Ctrl/⌘+C` / `Ctrl/⌘+V`
共用一个剪贴板。`TimelineEditor.tsx` 是剧情 `TimelineNode` 的适配器，各工作区只把本地
结构映射成中立轨道再折叠回去（按钮只写当前状态页签的通道，UI 动效每个目标一条轨道，
动作保留相对通道 / 参数绑定 / 结束姿态）。循环帧动画仍是有序帧列表，不属于关键帧界面。
时间尺以秒标注，`Ctrl/⌘+滚轮` 或缩放按钮可放大时间轴；每条轨道只列出有关键帧的通道
（加上当前选中的通道）。时间线工作区中直接输入「选中对象」的数值会立即写关键帧并刷新真实预览，提交后丢弃交互式
临时覆盖，预览继续按时间轴在播放头处求值（无需离开再进入）。

## 长文本节点

“长文本”用于替代对话框显示较长的数学讲解。检查器中的每一“步骤”对应一次玩家
推进：已完成步骤会保留在同一组草稿纸上，当前步骤继续逐字显示。勾选“在此步骤前
分页”会在该步骤前开始一张新纸；不勾选时，运行时会依据实际排版高度自动接到下一张。

- 每个步骤都必须有稳定且唯一的 ID 和非空文本。
- `paper` 可选；选择已登记的 GUI 素材可作为纸张底图，未选择时稿纸区域完全透明。
- 文本支持与 `say` 相同的 KaTeX、插值、暂停、速度和文本效果标记。
- 编辑器预览使用与游戏相同的 `@vectspace/text` 标记解析、KaTeX 配置和视觉行分页；
  自动分页可以在一个很长的步骤内部换页，但不会拆开一条公式。`manual` 模式只在
  作者添加的分页标记处换页，超出的单页会向下扩展。
- 全屏工作区顶部的 1920×1080 舞台直接渲染游戏同一份共享 `LongTextPanel`（纸张、测量根、
  分页器、揭示时钟与滚动控制器都是同一实现），顶部可播放/暂停当前步骤、补全文字、进入
  下一步骤或从头重播；滚轮或拖动即可滚动累计文稿，编辑用的布局框只通过顶部标签条移动、
  右下角手柄缩放。
- 运行时与存档会保存已写出的步骤，不保存当前滚动位置或打字动画。

## 虚拟素材文件夹与替换素材文件

素材分组、显示名和隐藏标记是**纯编辑器元数据**，与节点位置一起持久化在
`game/.vectspace/layout-v1.json`：

- `asset_folders`：`folder_id -> { parent_id, name, order }` 的稳定 ID 树；
  `asset_metadata`：`asset_id -> { folder_id?, display_name?, hidden? }`。
- 两个字段都是可选的；缺少它们的旧布局原样加载，不会被改写。宿主会修复手写的
  非法数据（非法文件夹 ID/名称、悬空父级、环、指向已删文件夹的引用），但**不会**
  因为素材被删除而丢弃元数据或拒绝打开项目。
- 文件夹只是分组：移动文件夹或素材、改名、隐藏都不会改变 manifest 路径、素材 ID、
  运行时引用或磁盘上的二进制文件。所有编辑都是普通可撤销的历史提交。
- 隐藏素材仍可在素材面板中管理和取消隐藏；**新选择**列表（检查器、时间线轨迹、
  地图、长文本、选择项图标、立绘表情、帧动画候选等）会排除隐藏素材，但当前已选中的
  隐藏 ID 仍会显示并标记为“已隐藏”，避免编辑时被静默清空。

替换素材二进制（“替换二进制”动作）保持同一逻辑 ID 和全部引用，只把该条目指向一个
**新路径**；旧文件永远不覆盖、不删除，作为未登记的回滚副本留在 `assets/` 中。

- 请求使用 `WireImportAssetRequest.replace_id`（必须等于 `id`）。宿主会拒绝未知 ID、
  类型不符、目标是合成动画素材、目标路径与原路径相同、实际格式不同，以及新图片与
  帧动画尺寸不一致的替换。替换**不会**复用已存在的同内容文件：它一定拥有新的暂存二进制。
- 暂存结果给出新路径（含 `absolute_path`）与 `replaced_from`；编辑器就地更新同一行素材
  与 manifest 条目，绝不新增第二行。保存前预览使用暂存路径，因此 URL/纹理缓存自动刷新。
- 保存事务把新二进制和 manifest/layout 一起写入同一个 journal，而旧的素材路径不会进入
  删除列表（素材二进制从来不由编辑器删除）。若源文件变化、token 失效、指纹过期或事务
  失败，旧登记与旧二进制都保持原样。
- 撤销会恢复旧路径与旧行；此时不再提交已失效的 token（前端仅在 manifest 的
  id/kind/path 仍与暂存记录一致时才发送能力句柄），因此不会出现路径不匹配的保存失败。

## 素材库界面与共享选择器

素材面板（素材标签页）是这些元数据的唯一编辑入口：

- **虚拟文件夹树**：可折叠的嵌套文件夹，行内可新建根文件夹、在任意文件夹下新建子
  文件夹、重命名文件夹、把文件夹移动到其它文件夹（含防环校验），以及把素材在文件夹
  之间移动。拖动是鼠标路径，素材详情的“移动到文件夹”下拉与文件夹的“移动文件夹”对话框
  是等价的键盘/菜单路径。空文件夹会显示“（空文件夹）”提示。
- **显示名与隐藏**：详情面板可编辑显示名（稳定 ID 与源文件路径始终单独可见），并可
  隐藏/取消隐藏。标记为隐藏的素材仍留在素材面板里（带“已隐藏”标记和“显示已隐藏”
  开关），只是不再出现在新的选择列表中。
- **搜索**：名称、稳定 ID、路径与文件夹都参与不区分大小写的搜索；下架只影响“新选择”。
  文件夹筛选里「未分组/根目录」只含**没有虚拟文件夹**的素材，不含子文件夹；选定某个
  文件夹时才包含它的子树。
- **替换二进制**：详情面板的“替换二进制文件…”打开一个锁定逻辑 ID 与类型的导入
  清单，校验扩展名与实际格式族，失败会给出原因；成功后该素材行显示“待保存”，撤销或
  取消时旧二进制与旧 token 都不受影响。宿主机**永远不接受**写回原始文件或任何先前
  暂存的替换路径：即使素材行已经指向暂存文件，原始路径仍然被保留，选择器也遵循同一
  规则，并在重名时自动给出唯一的 `_v2` / `_v3` 建议名、在应用前就地报冲突。被取代的
  暂存 token 与它的暂存二进制都保留以便重做，保存只会提交与 manifest 路径一致的那个 token。

所有素材选择入口共用 `AssetChooser` 与 `assetChoiceOptions`：可搜索、可按类型与文件夹
过滤、支持键盘（方向键移动、Enter 选中、Esc 关闭）与显式清除。布局元数据通过
`AssetLayoutProvider` 覆盖**整个编辑器**（包括长文本、章节地图、按钮、动作、UI 动效与
时间线等全屏工作区），所以每个工作区都遵守隐藏/显示名/文件夹策略。已接入：

- 节点检查器的所有素材字段（背景/立绘/GUI/BGM/环境声/音效/视频/字体）、选项 `gui`
  图标、幕布 `gui` 填充、长文本纸张素材与预览背景（保留 `__current__` / `__none__`
  哨兵选项）、动作预览基准立绘、按钮三态贴图、章节地图背景与装饰/热点贴图。
- 剧情时间线的轨道/事件素材（立绘/视频轨配置、SFX 事件）、工作区自身的新轨道与
  新事件默认值，以及项目页角色表情的立绘选择。
- 循环帧动画的“可选图片”候选也只列出未隐藏素材；已选中的隐藏帧仍保留在帧列表里。

**新选择/默认值**一律基于共享候选函数：没有任何可见素材时不会静默选一个隐藏素材，
而是使用空选择/禁用状态（例如新建角色表情的 ＋ 会被禁用并给出提示）。列表标签
优先显示显示名，稳定 ID 与路径用于区分；被选中的隐藏素材始终保留在列表中并标记
“已隐藏”。

## 文件与安全行为

- YAML 使用游戏本身的 Rust 数据类型、严格解析器和跨引用校验器。
- 保存前先验证完整候选项目，不会将已知无效的内容写入磁盘。
- 保存检查打开项目时的 SHA-256 指纹，防止覆盖外部编辑。
- 只序列化并替换字节实际变化的文档。
- 多文件保存先写入 `.vectspace/tmp/<save-id>/`；旧文件按相对路径备份到
  `.vectspace/backups/<save-id>/`，最多保留最近 10 代。这两类恢复数据均被 Git 忽略。
- 节点位置和画布视口写入 `game/.vectspace/layout-v1.json`，不污染剧情 YAML。
- 删除场景或素材登记不会删除原素材/YAML 文件，以便恢复。
- 只有实际修改的 YAML 文档会被规范化输出；未修改文档保留原字节（包括注释和手工
  格式）。多文件保存失败时会从事务备份恢复；备份和临时文件位于被 Git 忽略的
  `.vectspace/backups/`、`.vectspace/tmp/`，并保留最近 10 代。

## 界面结构

- `src/App.tsx`：项目状态、撤销历史与命令；路由（`src/app/routes.ts`）决定显示剧情图还是某个全屏工作区。
- `src/shell/`：顶栏、活动栏、状态栏、欢迎页、项目搜索、工作区统一顶栏。
- `src/ui/`：基于 Radix 无样式原语与 lucide 图标的通用组件（按钮、菜单、对话框、通知、提示）以及键盘策略
  （`keyboard.ts`）和“提交中字段”登记（`pendingCommits.ts`）。
- `src/styles/`：CSS 分层（`tokens` → `base` → `components` → `workspace`）；颜色只允许在
  `tokens.css` 中定义，由 `tokens.guard.test.ts` 检查。
- `preview.html` + `src/dev/`：仅开发用的浏览器设计预览（`npx vite` 后打开 `/preview.html`），用演示项目
  替代 Tauri 后端，便于检查界面。

## 快捷键

- `Ctrl+S`：先提交正在编辑的字段再保存（输入框内同样有效）
- `Ctrl+Z` / `Ctrl+Y`（或 `Ctrl+Shift+Z`）：撤销 / 重做；焦点在文本框里时作用于文字本身
- `Ctrl+F`：项目搜索
- `Ctrl+L`（或 `Ctrl+Shift+L`）：剧情图组合所选节点 / 布局组，或解散唯一选中的组；也可右键选择对应操作
- `Ctrl+Enter`：从选中节点预览
- `Delete`：删除选中节点 / 关键帧 / 地图对象（选中含布局组时不删除）
- `Esc`：关闭菜单 → 取消拖拽 → 输入框失焦 → 退出全屏工作区
- 完整列表见 `docs/editor-tutorial.zh-CN.md` 第 16 章。
- Windows WebView2 的浏览器级右键菜单、刷新/导航、新窗口、查看源代码、DevTools、缩放和 `F1`–`F12` 快捷键已关闭。
